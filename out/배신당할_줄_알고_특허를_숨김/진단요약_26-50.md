# 「배신당할 줄 알고 특허를 숨김」 sepia 진단 요약 (26~50화)

26~50화를 1~25화와 같은 기준(sepia review, 진단만)으로 처리한 결과다. 원고는 고치지 않았다. 1~25화 정리는 [진단요약.md](진단요약.md), 이 구간 합본은 [화별보고서_26-50.md](화별보고서_26-50.md).

- 판정: 25화 모두 부분 수정, 대부분 "손볼 곳 적음/거의 없음". 다시 쓰라는 판정은 없다.
- 작가 확인 항목 35건: **충돌 18건**, 복선(회수·미회수) 4건, 구조·문체 13건.
- 1장 중 49화↔30화 침출 시간, 50화 시료병 자리, 34화 "나흘"은 원문에서 직접 확인했다. 나머지는 AI 판단이니 원고와 대조할 것.

## 1. 먼저 정할 것

### 1~25화 진단요약의 큰 충돌은 어떻게 됐나

| 1~25화 문제 | 26~50화에서 |
|---|---|
| '원래 흐름' 연표 | **대부분 풀림.** 36화가 원래 흐름을 "회사를 두 번 잃은" 것으로 정리(2027년 1월 리사이클로 상실 → 새 회사 → 2031년 해임·매각)해 10·13·21화와의 어긋남이 대부분 해소됨 |
| 카이가 무엇을 알 수 있는지 | **계속됨.** 27·28화 원래 흐름에서 진우가 떠난 뒤의 일을 단정, 35화 이번 흐름에서 새로 적은 회색 노트 첫 장 문구까지 앎(1화 "네 눈에 보이는 것도 나는 못 본다"와 충돌). 42화 "말하지 않겠다고 밝힌 건 처음"은 1·36화에 이미 비슷한 장면이 있음(서술이라 고칠 수 있음) |
| 노트 날짜·증거 논리 | **일부 정리, 새 문제 하나.** 26화 정식 명세서 쪽은 3화와 맞음. 대신 30화 "회색 노트"에 10~11월 기록과 11월 말 조건이 들어 있다고 하는데, 21화에서 12월에 새 노트를 꺼내 조건 넷만 옮겨 적음 — 10~11월 기록이 든 노트가 따로 있는지 정해야 함 |

### 26~50화에서 새로 생긴 충돌

| 화 | 내용 |
|---|---|
| 30·49화 | **2세대 핵심 장치의 침출 시간.** 30화 "같은 산, 같은 온도, 같은 사흘" ↔ 49화 라인 첫 배치는 월요일 오후 투입 → "어제 저녁" 여과, 하루 남짓. 라인에서 시간을 줄였다면 한 줄(하루 이백 개 처리량과의 셈 포함)이 필요하고, 사흘을 지켰다면 날짜를 고쳐야 함 |
| 34화 | "화성 서버를 열어 본 지 나흘 만에 낸 출원" ↔ 27·33화 대성은 12월 26일 밤 서버 네 폴더를 통째로 받아 감(12화 첫날 로그도). 서술이라 "거래가 끝나고 나흘 만에" 등으로 고칠 수 있음 |
| 39화 | "30%를 아는 사람은 … 셋이었다" ↔ 26화 투자사 심사역, 22~23화 탁 변리사도 앎. 35행만 덜면 됨 |
| 43~45화 | 화학 기전: "코팅이 들떠 있으면 산이 알루미늄 판까지 덜 닿는다" — 들뜨면 오히려 판이 드러난다고 읽는 전문 독자가 있을 수 있음. 2세대 "쓴 기간 = 조건" 장치의 근거라 한 번 확인할 가치가 있음 |
| 44·47화 | 날짜 셈: 5월 20일 통보 + 제작 10주 + 한 주 = 8월 5일인데 "7월 마지막 주 목요일" |
| 49·50화 | 50화 "윤 대리가 가져간 병들이 놓여 있던 자리" 세 개가 빔 ↔ 49화 윤 대리는 진우 쪽 병에서 결정을 덜어 자기 병에 담아 감(진우 쪽 병은 남아야 함). 서술이라 바로 고칠 수 있음 |
| 29화 | 조기공개 신청서의 신청일 칸을 "3월 14일 출원 때 비워 둔 칸"이라 함 ↔ 26화 신청서는 12월에 따로 만든 서류 |
| 28화 | 경인 사장 "가을에 한 말 지켰구먼"(삼원계 4,800원) — 1~25화에 진우가 단가 인상을 약속한 장면이 없음 |
| 40·49화 | 40화 고 대표 메일을 "혼자" 열었다 ↔ 39화 오 기사가 함께 있었음, 49화 봉인 테이프에 "내 이름 하나만" ↔ 41화 윤 대리가 먼저 적음 |

### 반복 구조 (퇴고 참고)

- **"카이가 손쉬운 공격을 권함 → 진우가 거절 → 조항 한 줄로 막음"** 박자가 24·33·37·45화 네 번, 대성의 수가 매번 진우가 미리 깔아 둔 조항에 막힘. 카이의 권고가 맞는 경우나 진우가 한 번 틀리는 경우를 둘지 작가 판단.
- 대성 쪽 3인칭 장면이 진우보다 먼저 결과를 보여 주는 틀이 29~32화 연속.

### 복선

- **회수됨:** 9화 지훈 계정의 "바깥 주소" → 27화(대성 쪽 주소). 35·36·38화의 투자자 의심 → 39화 박 실장–문태영 통화.
- **아직 안 됨(1~25화에서 이어짐):** 12화 메모장의 "이름 하나", 5화 원래 흐름 2027년 봄 창고 화재(이야기 속 2027년 봄이 지났는데 언급 없음), 14화 차용증 원본, 20화 오 기사와의 12월 2일 대화.
- **새로 생김:** 32화 사장 강민혁과 "이 건, 누가 시작했나"(50화까지 안 나옴), 지훈의 5억 변제·행방(34화 이후 거의 없음), 41화 카이 "그 여자와는 엮이지 마라"(윤서하, 50화까지 이유 없음).
