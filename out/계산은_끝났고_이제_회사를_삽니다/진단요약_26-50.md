# 「계산은 끝났고 이제 회사를 삽니다」 sepia 진단 요약 (26~50화)

26~50화 sepia refactor 결과의 진단 정리다. 수정 내용은 [전후비교_26-50.md](전후비교_26-50.md), 화별 보고서 합본은 [화별보고서_26-50.md](화별보고서_26-50.md).

- 판정: 25화 모두 부분 수정, 대부분 "문장 층 국소 수정 2~4건". 다시 쓰라는 판정은 없다.
- 작가 확인 항목 138건: **화를 넘거나 같은 화 안의 충돌 29건**, 구조·문체 기록 109건.
- 1장 중 48화 "3개월 조항", 33화 캔커피, 46화 답변서는 원문에서 직접 확인했다. 나머지는 AI 판단이니 원고와 대조할 것.

## 1. 먼저 정할 것

1~25화보다 충돌이 작고 국소적이다. 아래는 이야기 논리나 이어지는 줄거리에 걸린 것들이다.

| 화 | 내용 |
|---|---|
| 48·49화 | 박 상무 해임을 "3개월 조항 때문에" 미룬다는 대사 ↔ 33화 조항은 "3개월 동안 임원 인사는 이사회 절차를 거친다"일 뿐이고, 정기 이사회도 3개월 안이라 미룰 이유가 되지 않음 |
| 45·49·50화 | 두 번째 장소 계약 명의: 45화 "내 돈으로, 내 이름으로, 회사 이름 안 붙이고" ↔ 49화 "계약은 법인 이름으로" ↔ 50화 개인 고객용 '연락처 주소' 칸 사용. 하나로 정해야 함 |
| 46화 | 답변서 "7월 31일 의향서에도 그렇게 적었습니다" — 7월 31일 의향서는 8월 1~14일에 사지 않았음을 보증할 수 없음(26화 의향서 문구는 "제출일까지") |
| 29·32·39화 | 본부장의 "둘 가운데 하나를 고르라"는 조건: 39화는 승인서 손글씨 줄을 짚으며 말하지만, 손글씨 줄은 이해충돌 조항(29화)이고 고르라는 조건은 8월에 말로만 붙음(32화 "승인서에 없는 조건이다") |
| 31·32화 | 본입찰 초안 기한(8/12 수요일) ↔ 반기보고서(8/14 금요일)를 보고 값을 정하겠다는 대사, 32화 "다음 주 월요일 최종본" |
| 39·42화 | 39화는 노 차장을 아뜰리에 저가 라인을 "처음부터 맡았던 사람"으로 서술 ↔ 42화 "실무는 기 차장이 했다" |
| 36·37·50화 | 염태호가 지금도 사외이사인지, 37화에서 칠호가 이미 읽은 회사인지 — 50화에서 처음 나오는 이유 |
| 33화 | 오 주임 "아무도 안 마셨잖아요" ↔ 11화 "대리만 캔커피 하나를 집었다", 오 주임도 한 모금 마심 |
| 13·23·26화 | 23화 "입점 첫 달 = 5월 실적" ↔ 13화 4월 6일 입점. 26화가 23화 설정을 따름(1~25화 쪽 수정 필요) |

### 화를 넘는 구조 경향 (고칠 대상이라기보다 퇴고 참고)

- **속생각이 화마다 6~8줄**이고 대부분 바로 앞 대사·서술을 되풀이함. 보호 대상이라 손대지 않았지만 화당 수를 줄일지는 작가가 정할 일.
- **"칠호 권고 → 주인공이 뒤집고 맞음" 틀이 42·44·45화 세 화 연속** 등 반복되고, 위기가 같은 화 안에서 바로 풀리는 평평한 고조(16화 보고서부터 이어짐).
- 주인공 없는 상무실·법무법인 장면을 3인칭으로 쓴 곳이 28·34·40·46·49화(13화부터 이어짐).
