# 「경리팀 막내가 재계를 뒤집음」 sepia 진단 요약 (51~75화, 개정판)

51~64화 개정판과 65~75화 새 원고를 sepia review(진단만)로 처리한 결과다. 이전판 51~64화 진단은 [이전판_51-64/](이전판_51-64/), 이 구간 합본은 [화별보고서_51-75.md](화별보고서_51-75.md).

- 판정: 25화 모두 부분 수정. 다시 쓰라는 판정은 없다.
- 작가 확인 항목: 이전판 지적의 해결 여부 102건, **공개분(1~15화)과 어긋남 14건**, 미공개분 안 충돌·사실 확인 40건, 구조·기록 19건.
- 1장 중 이전판 핵심 지적 세 건(59화 '예견안' 대사, 61화 청산 방향, 52·53화 추석 날짜)의 해결과 52:97·54:98 중복 구절은 원문에서 직접 확인했다. 나머지는 AI 판단이니 원고와 대조할 것.

## 1. 이전판 지적은 개정판에서 어떻게 됐나

| 이전판 지적 | 개정판 |
|---|---|

## 2. 먼저 정할 것 (51~75화)

| 화 | 내용 |
|---|---|

| 65·68·71·73·74화 | 도현이 진우 판단에 자기 돈을 맡기는 장면 다섯 ↔ 4화 '기생' 원칙(공개분). 의도된 변화인지 한 줄이 필요 |
| 69·71·74화 | 진우가 기록 밖의 사실을 말로 가림(답변서, "상의는 안 한다", "한성에 아는 사람이 없습니다") ↔ 12화 도현 "거짓은 쓰지 마"(공개분). 인물 줄기로 의도한 것인지 |
| 56·72화 | 세무 조사 범위: 56화 2019년 거래 조사 ↔ 72화 "2018년은 봤으니 2019년". 56화만 결정 사흘 만에 조사관 착석(72화는 사전통지 15일로 제도대로) |
| 54·62화 | "목은 끝까지 안 놓겠다" ↔ 62화 길목이 화면 밖에서 6주 만에 팔림. 세 번째 출자자 정산도 끝내 안 나옴 |
| 66·69·70화 | 2020년 2월 28일 국회 정무위 공매도 금지 요구 — 금감원 답변서·한성 보고서의 축이라 실제 날짜·주체 확인이 특히 중요 |
| 51~75화 | 둥근 따옴표, 화 끝 "══" 줄 없음, 서술 호칭 '소연' — 개정판 표기로 확정할지 |
